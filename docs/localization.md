# Localization

Aiko supports **English (`en`)** and **Thai (`th`)** using Flutter's `gen-l10n`.

## Files

| File | Role |
| --- | --- |
| `l10n.yaml` | Generator config: ARB directory `lib/l10n`, template `app_en.arb`, output `app_localizations.dart`, non-nullable getters |
| `lib/l10n/app_en.arb` | Source strings (template), 256 keys |
| `lib/l10n/app_th.arb` | Thai translations (same keys) |
| `lib/l10n/app_localizations*.dart` | Generated by `flutter pub get` / build; gitignored. Don't edit. |
| `lib/app/locale_controller.dart` | `AppLocaleController`: which locale to render |

`pubspec.yaml` sets `flutter: generate: true`, and `AikoApp` registers `AppLocalizations.delegate` with the global Material, Widgets and Cupertino delegates.

## Choosing the locale

`AppLocaleController` resolves the locale on startup:

1. A saved choice (`aiko_language_code`, `en` or `th`) wins. It's a synced preference, so it follows the user across devices when signed in.
2. Otherwise the device language is used if supported ("System default").
3. Otherwise the first supported locale (`en`).

Settings → Language offers System default, English and Thai. `followSystemLocale()` deletes the saved code so the app tracks the device again.

## Adding or changing a string

1. Add the key to `app_en.arb` (with an `@key` description when the meaning isn't obvious) and the translation to `app_th.arb`.
2. Run `flutter pub get` (or any build) to regenerate.
3. Use it: `AppLocalizations.of(context).yourKey`.
4. Placeholders use ICU syntax, for example `"budgetUsed": "You've used {percent}% of {name}"`, with matching `placeholders` metadata.

## Adding a language

1. Create `lib/l10n/app_<code>.arb` with every key.
2. Add the code to `AppLocaleController.localeFor` and to `_languageOptions` in `lib/features/settings/presentation/settings_screen.dart`.
3. Check fonts: Hanken Grotesk and Manrope have no Thai glyphs, so `AikoTypography` registers Noto Sans Thai as a fallback. Add a fallback for any other script that needs one.
4. Check number and currency formatting with `intl` (`Money.format(locale: …)`).

## Coverage today

Only the five destination labels (`aikoPrimaryDestinations`, used by the bottom bar and the sidebar), Settings and parts of the Overview read from `AppLocalizations`; the sidebar's Tools, **New transaction** and Profile labels are still English. Most screens still hard-code English. When you touch a screen, move its user-facing strings into the ARB files ([Known gaps](features.md#known-gaps)).

Money and dates use `intl` with the active locale. Money is formatted by `MoneyFormatter.format` (`lib/core/formatting/money_formatter.dart`), which picks the symbol from the currency code.
