Daily money Local first

Production-shaped from the beginning.

Aiko is built around offline-first data, decimal-safe money, Supabase sync, and a design system that keeps screens consistent as the product grows.

Offline first Core finance workflows read and write locally, then sync when the user is authenticated.
Decimal safe Money values use decimal arithmetic so financial math avoids floating-point drift.
Data first Aiko guidance supports the numbers instead of covering charts, balances, or forms.

Private by design, useful by default.

Personal finance data should feel handled, not exposed. Aiko keeps the core app local-first, uses row-level security in Supabase, and treats AI as an opt-in assistant for explanations and recommendations.

  • ✓Local SQLite store for core money data and offline use.
  • ✓Supabase authentication, sync, and row-level security policies.
  • ✓PIN and biometric protection for sensitive mobile sessions.

Finance needs trust before flair.

The interface stays calm, readable, and explicit about what each number means.
